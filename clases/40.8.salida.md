Código:

```csharp
using System;
using System.Linq;

public static class Program
{
    public static void Main()
    {
        int[] numeros = { 7, 2, 9, 4, 3, 8, 1, 6, 5 };
        int[] ordenados = QuickSort(numeros);

        Console.WriteLine(string.Join(", ", ordenados));
    }

    public static int[] QuickSort(int[] numeros)
    {
        if (numeros.Length <= 1)
        {
            return numeros;
        }

        int pivote = numeros[0];
        int[] menores = numeros.Skip(1).Where(n => n <= pivote).ToArray();
        int[] mayores = numeros.Skip(1).Where(n => n > pivote).ToArray();

        return QuickSort(menores)
            .Concat(new[] { pivote })
            .Concat(QuickSort(mayores))
            .ToArray();
    }
}
```

## Explicación línea por línea

### `using System;`
Trae el espacio de nombres `System`, que contiene cosas básicas del lenguaje, como:

- `Console`
- tipos primitivos
- utilidades generales

En este programa se usa principalmente para imprimir en pantalla con `Console.WriteLine`.

---

### `using System.Linq;`
Trae funcionalidades de LINQ.

Se usa para trabajar con colecciones de forma expresiva, por ejemplo:

- `Skip(1)` → saltar el primer elemento
- `Where(...)` → filtrar elementos
- `Concat(...)` → concatenar secuencias
- `ToArray()` → convertir el resultado en arreglo

La lógica del quicksort simple se apoya mucho en estas operaciones.

---

### `public static class Program`
Define una clase llamada `Program`.

- `public`: accesible desde afuera.
- `static`: no hace falta instanciarla para usar sus métodos.
- `class`: es una clase normal de C#.

En este caso, todo el programa vive dentro de esta clase.

---

### `public static void Main()`
Es el punto de entrada del programa.

Cuando ejecutás la aplicación, C# empieza por acá.

- `public`: visible para el runtime.
- `static`: no hace falta crear un objeto `Program`.
- `void`: no devuelve nada.

La lógica del programa arranca en este método.

---

### `int[] numeros = { 7, 2, 9, 4, 3, 8, 1, 6, 5 };`
Crea un arreglo de enteros con valores desordenados.

Este arreglo es la entrada que vamos a ordenar.

La idea es simple:

- tomar estos números
- pasarlos por `QuickSort`
- obtener una nueva versión ordenada

---

### `int[] ordenados = QuickSort(numeros);`
Llama al método `QuickSort` y guarda el resultado en `ordenados`.

Acá pasa lo importante:

- `numeros` entra desordenado
- `QuickSort` devuelve un nuevo arreglo ordenado
- el resultado se guarda en `ordenados`

La lógica de quicksort en esta versión no ordena “en el lugar”, sino que crea nuevos arreglos.

---

### `Console.WriteLine(string.Join(", ", ordenados));`
Imprime los números ordenados separados por comas.

`string.Join(", ", ordenados)` convierte el arreglo en texto.

Ejemplo de salida:

## Método `QuickSort`

### `public static int[] QuickSort(int[] numeros)`
Define una función que:

- recibe un arreglo de enteros
- devuelve otro arreglo de enteros ordenado

Esta es la implementación del algoritmo quicksort, pero hecha de forma muy simple y legible.

---

### `if (numeros.Length <= 1)`
Esta es la condición base de la recursión.

Significa:

- si el arreglo tiene 0 elementos
- o 1 elemento

entonces ya está ordenado automáticamente.

#### ¿Por qué?
Porque un arreglo vacío o con un solo elemento no necesita ordenamiento.

Esta línea evita que la función siga llamándose infinitamente.

---

### `return numeros;`
Si el arreglo ya tiene 0 o 1 elemento, se devuelve tal cual.

No hace falta procesarlo más.

La lógica acá es:

- “esto ya está ordenado”
- “no lo toco”

---

### `int pivote = numeros[0];`
Elegimos el primer elemento como pivote.

El pivote es el valor de referencia que divide el arreglo en dos grupos:

- menores o iguales al pivote
- mayores que el pivote

Ejemplo si el arreglo es:

```csharp
{ 7, 2, 9, 4 }
```

el pivote es `7`.

La idea central de quicksort es justamente esta división.

---

### `int[] menores = numeros.Skip(1).Where(n => n <= pivote).ToArray();`
Esta línea construye el arreglo de elementos menores o iguales al pivote.

Vamos por partes:

#### `numeros.Skip(1)`
Salta el primer elemento del arreglo.

¿Por qué?
Porque el primer elemento ya fue usado como pivote, y no queremos compararlo consigo mismo.

Si `numeros` es:

```csharp
{ 7, 2, 9, 4 }
```

entonces `Skip(1)` da:

```csharp
{ 2, 9, 4 }
```

---

#### `.Where(n => n <= pivote)`
Filtra solo los números que sean menores o iguales al pivote.

Si el pivote es `7`, entonces de `{ 2, 9, 4 }` quedan:

```csharp
{ 2, 4 }
```

La lógica acá es separar lo que va a la izquierda del pivote en el resultado final.

---

#### `.ToArray()`
Convierte el resultado en un arreglo concreto.

`Skip` y `Where` trabajan con secuencias; `ToArray()` materializa el resultado como `int[]`.

---

### `int[] mayores = numeros.Skip(1).Where(n => n > pivote).ToArray();`
Esta línea construye el arreglo de elementos mayores que el pivote.

Hace algo muy parecido a la línea anterior, pero con la otra mitad:

- toma todos menos el pivote
- filtra los que son mayores
- los guarda en `mayores`

Siguiendo el ejemplo anterior:

```csharp
{ 7, 2, 9, 4 }
```

con pivote `7`, los mayores son:

```csharp
{ 9 }
```

---

## La recursión

### `return QuickSort(menores)`
Primero ordenamos la parte izquierda: los valores menores o iguales al pivote.

La idea es:

- si ya sabemos ordenar “lo que va a la izquierda”
- y también “lo que va a la derecha”
- entonces podemos reconstruir todo ordenado

---

### `.Concat(new[] { pivote })`
Agrega el pivote al medio.

`new[] { pivote }` crea un arreglo de un solo elemento, por ejemplo:

```csharp
{ 7 }
```

El pivote siempre va entre ambos grupos:

- a la izquierda: valores menores o iguales
- en el centro: pivote
- a la derecha: valores mayores

---

### `.Concat(QuickSort(mayores))`
Luego agregamos la parte derecha, pero ordenada recursivamente.

O sea:

- ordenamos primero los menores
- ponemos el pivote
- ordenamos luego los mayores

Esto reconstruye el resultado final ya ordenado.

---

### `.ToArray();`
Convierte toda la secuencia concatenada en un arreglo final.

Es el retorno real del método.

---

## Cómo piensa el algoritmo

La lógica del quicksort acá es esta:

1. Elegir un pivote
2. Separar el resto en dos grupos:
   - menores o iguales
   - mayores
3. Ordenar recursivamente ambos grupos
4. Unir:
   - menores ordenados
   - pivote
   - mayores ordenados

---

## Ejemplo paso a paso

Si entran estos números:

```csharp
{ 7, 2, 9, 4, 3, 8, 1, 6, 5 }
```

### Primer pivote: `7`
Se divide en:

- menores: `{ 2, 4, 3, 1, 6, 5 }`
- mayores: `{ 9, 8 }`

Resultado parcial:

```csharp
QuickSort({ 2, 4, 3, 1, 6, 5 }) + 7 + QuickSort({ 9, 8 })
```

---

### Luego se ordena `{ 2, 4, 3, 1, 6, 5 }`
Pivote: `2`

- menores: `{ 1 }`
- mayores: `{ 4, 3, 6, 5 }`

Resultado:

```csharp
{ 1 } + 2 + QuickSort({ 4, 3, 6, 5 })
```

---

Y así sigue, hasta que todos los subarreglos tengan tamaño 0 o 1.

En ese momento, la recursión termina y todo se va recomponiendo.

## Idea clave de la claridad de esta versión

Esta implementación es muy fácil de entender porque:

- no modifica el arreglo original
- no usa índices complicados
- no hace swaps
- divide el problema en partes muy visibles

La contra es que usa más memoria y es menos eficiente, pero para aprender y leer la lógica, es excelente.
